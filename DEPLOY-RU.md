# Kritzelei v17 — обновление GitHub Pages

Сделайте резервную копию заметок внутри Kritzelei, прежде чем обновлять файлы.

1. Распакуйте `Kritzelei-v17-GitHub.zip`.
2. Откройте свой репозиторий Kritzelei на GitHub.
3. Замените **все файлы в корне** содержимым архива (не загружайте ZIP как один файл).
4. Нажмите `Commit changes` и дождитесь публикации GitHub Pages.
5. Откройте установленную Kritzelei на iPad. Версия в меню `…` должна показывать **v17**. При необходимости закройте и снова откройте приложение, чтобы обновился кеш. Не удаляйте установленную иконку/приложение: заметки хранятся локально.

## Новый режим

Выберите **Перо**. В настройках пера появится галочка **«Авто: письмо / чертёж»**. Включите — после поднятия стилуса приложение будет различать свободное письмо и достаточно чёткие крупные линии, дуги, окружности и другие фигуры. Снимите галочку — вернётся прежнее поведение v16, включая старое выравнивание после удержания. Состояние галочки запоминается на iPad; изначально она выключена.

Алгоритм геометрический, без отправки почерка в интернет. Распознавание не гарантировано: короткие и неясные линии/дуги сохраняются как рукописные штрихи. Для точных чертежей остались специальные инструменты «Линия» и «Фигуры». Ошибочное распознавание отменяется кнопкой «Назад» (Undo).

Все функции v15 (PDF и удлинение листов, палитра) и v16 (калькулятор/стилус) сохранены.
