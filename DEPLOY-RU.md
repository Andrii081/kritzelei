# Kritzelei v24 — замена файлов на GitHub

## Обновление
1. В текущей Kritzelei сохраните резервную копию заметок (Save backup). Не удаляйте приложение на iPad.
2. Скачайте `Kritzelei-v24-GitHub.zip` и распакуйте его.
3. В GitHub-репозитории `Andrii081/kritzelei` загрузите **содержимое архива в корень** репозитория, заменив старые файлы. Нажмите **Commit changes**.
4. Откройте Kritzelei на iPad и проверьте номер **v24**. При необходимости перезапустите приложение после обновления GitHub Pages.

## Как пользоваться
- **Координаты**: включите «Авто: письмо / черчение» в инструменте «Перо». Нарисуйте крест из двух длинных пересекающихся линий. При удачном распознавании появятся оси X/Y со стрелками и числами через одну клетку. Для старых распознанных осей v23 подписи добавятся при открытии блокнота.
- **Изменить шаг**: удерживайте стилусом **любое число у оси** около 0,5 секунды. В появившемся окне введите `50` и нажмите «Применить». Будут подписаны 50, 100, 150 и т. д. Штрихи останутся на каждой клетке. Меняются обе оси одной системы; настройка сохраняется.
- **Без OCR**: автоматическое распознавание букв/цифр и замена почерка отключены, соответствующие галочки убраны. Ранее преобразованные символы остаются доступными для удаления обычным ластиком.
- **Быстрое зачёркивание**: включите «Стирать быстрым зачёркиванием». Не отрывая пера, за одну секунду несколько раз пересеките ненужный объект — минимум **4 различных геометрических пересечения с существующими штрихами**. Сотрутся только реально пересечённые объекты, в одно отменяемое действие. Несколько отдельных штрихов не считаются жестом. Рядом расположенные элементы, которых жест не пересёк, не должны удаляться.

## Ограничения
- Точное срабатывание распознавания осей и жеста зависит от почерка и траектории. Протестировано в браузере с имитацией пера, **не на настоящем iPad**. Если жест случайно удалил нужное — нажмите «Отмена».
- Если новые файлы загружены, а интерфейс старый, проверьте номер версии в приложении и дайте GitHub Pages обновить файлы. Не удаляйте приложение и не очищайте Safari без резервной копии.
