# Kritzelei v21 — обновление на GitHub

1. **Обязательно сначала сделай резервную копию** в текущей Kritzelei (меню → Сохранить резервную копию). Не удаляй приложение с iPad и не очищай Safari.
2. Распакуй `Kritzelei-v21-GitHub.zip` и загрузи **все файлы из архива** в корень репозитория `Andrii081/kritzelei` (там, где `index.html`). Подтверди замену, нажми **Commit changes**.
3. Открой Kritzelei на iPad с интернетом и проверь надпись **v21** в меню. При старой версии закрой и снова открой установленное приложение после обновления GitHub Pages.
4. Инструмент **Перо** → **Авто: письмо / черчение** (включено для новых установок). Один прямой штрих выпрямляется автоматически. Ровные горизонтали и вертикали располагаются точно на линиях клетки. Две достаточно длинные оси с общей начальной точкой автоматически распознаются как **X** и **Y**, третья диагональная — как **Z**. Для распознавания осей сначала нарисуй их из одного начала, под углом около 90°.
5. **Стирать быстрым зачёркиванием** (включено для новых установок). Проведи 4 и более раз туда-обратно поверх существующей записи, не отрывая стилус. Обычные буквы и отдельный штрих НЕ должны стираться. При необходимости отключи галочку.
6. **Красивый рукописный почерк**: сохраняет естественные штрихи и сглаживает их сразу. Если отдельную букву удалось надёжно распознать, она заменяется на рукописный шрифт Bad Script (кириллица и латиница) либо подходящий рукописный шрифт другого языка. Буквы, которые распознать нельзя, остаются чернилами. Первое использование OCR и загрузка внешнего шрифта требуют интернета.
7. Используй **Отмена**, если результат тебе не нравится. Старые блокноты автоматически не перерисовываются.

**Ограничение:** OCR рукописных букв в браузере не гарантирует корректного определения каждой буквы или иероглифа. Точность на реальном Apple Pencil необходимо проверить.
