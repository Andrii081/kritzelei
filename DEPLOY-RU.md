# Kritzelei v16 — инструкция по обновлению на GitHub

Готовый комплект файлов веб-приложения для iPad (PWA). Это не .ipa-файл; запуск через GitHub Pages / Safari.

## Перед обновлением

1. Откройте старую Kritzelei на iPad и нажмите **Save backup / Сохранить резервную копию**. Сохраните файл отдельно, например в «Файлы»/iCloud Drive.
2. Проверьте, что скачанная резервная копия существует. Не удаляйте установленную на главный экран Kritzelei и не очищайте данные Safari до проверки обновления.

## Загрузка на GitHub

1. Распакуйте архив `Kritzelei-v16-GitHub.zip`.
2. Откройте репозиторий `Andrii081/kritzelei` на GitHub (либо репозиторий, в котором размещена ваша версия).
3. Замените файлы в **корне репозитория**, прежде всего `index.html` и `sw.js`; загрузите **все остальные** файлы из распакованного архива, включая `icon-180.png` (без дополнительной вложенной папки `Kritzelei-v16`).
4. Подтвердите изменения (Commit changes) в ветке, из которой публикуется GitHub Pages (обычно `main`).
5. Откройте ссылку GitHub Pages. Для репозитория выше это `https://andrii081.github.io/kritzelei/`.
6. В Safari полностью закройте и снова откройте Kritzelei, при необходимости обновите вкладку. Номер версии в приложении должен быть **v16**. Если кнопка обновления появилась в приложении — нажмите её после сохранения записей.

## Что изменено

- Между любыми страницами PDF можно нажать **＋ ⅓ A4 · Клетка/Grid**; также есть кнопка после каждой страницы и в обзоре страниц. Вставка доступна перед первой PDF-страницей.
- Такой лист создаётся в клетку размером **⅓ A4**. Когда перо или текст доходят примерно до предпоследней строки, он увеличивается ещё на **⅓ A4**. Повторяется сколько нужно.
- Автопродление работает независимо от режима «Endless page»; PDF-фоны не растягиваются и не меняются.
- Цветной кружок теперь открывает встроенную палитру: 72 варианта, ползунки оттенка/насыщенности/светлоты, поле HEX, а также дополнительный стандартный системный выбор цвета. Палитра есть для пера, маркера, фигур, текста и выделенных элементов.
- Новые листы и их длина сохраняются в блокноте; при экспорте длинные заметки разбиваются на страницы PDF.

## Важно

- Заметки хранятся в данных браузера на iPad, а не в самом GitHub. Новая версия использует прежнее хранилище, но перед обновлением обязательно сохраните резервную копию.
- Не переименовывайте файлы и не удаляйте библиотечные JS-файлы.
- Встроенные тесты выполнены в Chromium; обновление ещё стоит дополнительно проверить в Safari непосредственно на вашем iPad.

## Исправление калькулятора для Apple Pencil (v16)

Теперь кнопки калькулятора реагируют на первое касание Apple Pencil: цифры,
арифметические знаки, переключение DEG/RAD и 2nd, стрелки и история.
Защита от двойного события не позволяет одной попытке нажать кнопку дважды.
Обычное нажатие пальцем и ввод с клавиатуры продолжают работать.

Если iPad всё ещё показывает старую версию, открой приложение при подключённом
интернете, сверни и снова открой. В меню «…» проверь номер версии **v16**.
При необходимости перезапусти приложение с домашнего экрана.
