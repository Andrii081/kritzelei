# Kritzelei v31 — полный комплект для замены на GitHub

Это полный исходный репозиторий, а не только изменённый index.html.

## Обновления
- Сохранены все функции v27/v28: PDF, расширяемые листы, распознавание осей X/Y/Z и масштаб, калькулятор, палитра, жест стирания, языки и офлайн-кеш.
- Знак `=` по-прежнему распознаётся из двух отдельных коротких горизонтальных черт.
- Улучшена проверка варианта `=` из одного непрерывного жеста с двумя короткими горизонтальными участками и диагональной связкой.
- **Важно:** небольшая рукописная латинская Z может выглядеть *точно так же* как такой жест. Гарантировать отличение без специального режима невозможно; неопределённые варианты остаются рукописными.

## Как заменить
1. В старом приложении сохранить резервную копию заметок.
2. Распаковать ZIP. Загружать на GitHub именно *содержимое архива*, не папку `Kritzelei-v31` и не ZIP-файл.
3. В репозитории Kritzelei выбрать **Add file → Upload files**, загрузить все файлы из архива в корень. Подтвердить замену и сделать **Commit changes**.
4. Подождать публикации GitHub Pages, затем открыть приложение в Safari (при необходимости обновить страницу); версия должна показывать `v31`.
5. Не удалять установленное веб-приложение и не очищать Safari без сохранённой резервной копии заметок.

В корне архива присутствуют index.html, sw.js, 16 manifest-файлов, три иконки, три JS-библиотеки PDF/QR, README, лицензии и инструкции. `equals-test.png` — вспомогательная иллюстрация, её можно тоже загрузить.


## Обновление v31
На клетчатой странице автоматическое выпрямление и прилипание к сетке применяется только для линии **строго длиннее двух клеток** (10 мм на обычной клетке 5 мм). Более короткие штрихи пера не меняются. Инструмент «Линия» для коротких отрезков больше не притягивает концы к клеткам; геометрически это всё ещё инструмент прямой линии. Намеренно нарисованный знак «=» распознаётся как раньше.
